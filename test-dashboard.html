🐛 Common Issues & Solutions

  • No subtitles loading: Try different videos, some may block API access
  • Extension not injecting: Check manifest.json and reload extension
  • Highlighting not working: Ensure video is playing and CSS is loaded
  • Side panel not opening: Click extension icon, check permissions
